На схеме перечислены шесть основных команд для разбора логов.

## Команды для разбора логов

* **GREP**

  Ищет во входных файлах строки, соответствующие одному или нескольким шаблонам.

* **CUT**

  Извлекает выбранные части каждой строки входных файлов и записывает их в стандартный поток вывода.

* **SED**

  Читает указанные файлы и изменяет входные данные согласно заданной последовательности команд.

* **AWK**

  Просматривает каждый входной файл и находит строки, соответствующие заданным шаблонам.

* **SORT**

  Сортирует текстовые и двоичные файлы по строкам.

* **UNIQ**

  Сравнивает соседние строки указанного файла и выводит по одной копии каждой уникальной строки.

Эти команды часто объединяют, чтобы быстро извлекать полезную информацию из логов. Например, следующая последовательность выводит временные метки из второго столбца для исключений в xxService.

```bash
grep “xxService” service.log | grep “Exception” | cut -d” “ -f 2
```
