Мы создали шаблон для решения различных проблем с дизайном системы в ходе интервью.

![План системного проектирования: подробное руководство](https://assets.bytebytego.com/diagrams/0324-system-design-blueprint.png)

Надеюсь, этот контрольный перечень будет полезен для ваших дискуссий в ходе собеседования.

Это касается в краткой форме следующих вопросов для обсуждения:

*   Балансировка нагрузки
*   API-шлюз
*   Протоколы взаимодействия
*   Сеть доставки контента (CDN)
*   База данных
*   Кеш
*   Очередь сообщений
*   Генерация уникальных идентификаторов
*   Скалабельность
*   Доступность
*   Производительность
*   Безопасность
*   Отказоустойчивость и способность к восстановлению
*   И еще больше
