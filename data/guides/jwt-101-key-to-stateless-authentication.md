JWT (JSON Web Token) — открытый стандарт безопасной передачи информации между двумя сторонами. JWT широко применяются для аутентификации и авторизации.

JWT состоит из трёх основных частей:

1. Заголовок (Header)

Заголовок каждого JWT указывает алгоритм, используемый для подписи токена. Он записывается в формате JSON.

2. Полезная нагрузка (Payload)

Полезная нагрузка содержит утверждения (claims) и данные пользователя. Утверждения бывают зарегистрированными, публичными и частными.

3. Подпись (Signature)

Подпись обеспечивает защиту целостности JWT. Она вычисляется на основе закодированных заголовка и полезной нагрузки с использованием выбранного алгоритма и секретного ключа.

JWT можно подписать двумя способами:

* **Симметричная подпись**

  Для создания и проверки подписи используется один секретный ключ. Сервер, подписывающий JWT, и система, проверяющая подпись, должны использовать один и тот же ключ.

* **Асимметричная подпись**

  Токен подписывается закрытым ключом, а подпись проверяется открытым. Закрытый ключ хранится на сервере и защищается от раскрытия. Открытый ключ можно передавать всем системам, которым нужно проверять подпись токена.
