Что такое **WebAssembly** (WASM) и почему эта технология привлекает столько внимания?

Схема показывает, как с помощью WASM выполнять в браузере нативный код на C, C++ и Rust.

Традиционно в браузере используют JavaScript. При интерпретируемом выполнении его производительность уступает нативному коду на C/C++.

WASM позволяет **повторно использовать** существующие библиотеки нативного кода, написанные на C, C++, Rust и других языках, и запускать их в браузере. Такие веб-приложения работают с производительностью, близкой к нативной.

Например, в браузере можно запустить написанную на C++ библиотеку **кодирования и декодирования видео**.

Это открывает новые возможности для облачных и **периферийных вычислений**. Бессерверные приложения могут потреблять меньше ресурсов и запускаться практически мгновенно.
