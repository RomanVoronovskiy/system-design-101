* **Планирование:** инженеры Netflix используют JIRA для планирования и Confluence для документации.
* **Программирование:** основной язык серверных сервисов — Java. Для других задач используются и другие языки.
* **Сборка:** преимущественно используется Gradle. Для разных сценариев создаются плагины Gradle.
* **Упаковка:** приложение и зависимости включаются в образ Amazon Machine Image (AMI), предназначенный для выпуска.
* **Тестирование:** в культуре эксплуатации Netflix особое внимание уделяется разработке инструментов хаос-тестирования.
* **Развёртывание:** для канареечных выпусков Netflix использует собственный инструмент Spinnaker.
* **Мониторинг:** метрики централизованно собираются в Atlas, а Kayenta обнаруживает аномалии.
* **Обработка инцидентов:** инциденты распределяются по приоритету; для работы с ними используется PagerDuty.
