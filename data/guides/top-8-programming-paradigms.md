## Императивное программирование

Программа описывает последовательность действий, изменяющих её состояние. Такой стиль поддерживают C, C++, Java, в определённой степени Python и многие другие языки.

## Декларативное программирование

Основное внимание уделяется описанию логики и требуемого результата без явного задания потока управления. Функциональное программирование — популярная разновидность декларативного подхода.

## Объектно-ориентированное программирование — ООП

В центре находятся объекты, объединяющие данные — атрибуты — и поведение — методы или функции. Среди распространённых объектно-ориентированных языков — Java, C++, Python, Ruby и C#.

## Аспектно-ориентированное программирование — AOP

Цель подхода — выделить в модули сквозную функциональность, затрагивающую разные части системы. Один из самых известных инструментов — AspectJ, расширяющий Java возможностями AOP.

## Функциональное программирование

Вычисления рассматриваются как вычисление значений математических функций. Акцент делается на неизменяемых данных и декларативных выражениях. Подход поддерживают Haskell, Lisp, Erlang, а также отдельные возможности JavaScript, Python и Scala.

## Реактивное программирование

Работает с асинхронными потоками данных и распространением изменений. Подход полезен для событийных приложений и потоковой обработки данных.

## Обобщённое программирование

Позволяет создавать гибкий, повторно используемый код, не привязанный к конкретным типам. Алгоритмы и структуры данных описываются без указания типов, с которыми будут работать. Подход широко используется в библиотеках и фреймворках для списков, стеков, очередей, сортировки и поиска.

## Конкурентное программирование

Организует одновременное выполнение нескольких задач или процессов, улучшая производительность и использование ресурсов. Применяется в многопоточных и конкурентных веб-серверах, параллельной обработке и высокопроизводительных вычислениях.
