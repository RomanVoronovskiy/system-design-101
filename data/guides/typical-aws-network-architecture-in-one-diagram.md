Amazon Web Services (AWS) предлагает широкий набор сетевых сервисов для создания безопасной, масштабируемой и высокодоступной инфраструктуры. Компоненты сетевой архитектуры AWS обеспечивают связь с интернетом, удалёнными сотрудниками, корпоративными центрами обработки данных и другими ресурсами AWS.

## Основные компоненты

* **VPC (Virtual Private Cloud)**

  В основе сетевых сервисов AWS лежит Amazon VPC. Он позволяет выделить логически изолированную часть облака AWS и запускать в ней ресурсы в виртуальной сети с заданными пользователем параметрами.

* **AZ (Availability Zone, зона доступности)**

  Зона доступности — один или несколько отдельных центров обработки данных в регионе AWS с резервированием питания, сетевого оборудования и каналов связи.

Рассмотрим по порядку способы сетевого подключения.

## Сетевые подключения

### 1. Подключение к интернету — Internet Gateway (IGW)

Интернет-шлюз IGW обеспечивает двустороннюю связь между VPC и интернетом.

### 2. Удалённые сотрудники — Client VPN Endpoint

AWS Client VPN позволяет удалённым сотрудникам безопасно подключаться через интернет к ресурсам AWS или локальной корпоративной сети. Это управляемое VPN-решение, которое упрощает организацию защищённого доступа.

### 3. Подключение корпоративного ЦОД — Virtual Gateway (VGW)

VGW — VPN-концентратор на стороне Amazon для соединения Site-to-Site VPN между вашей сетью и VPC.

### 4. VPC Peering

VPC Peering соединяет две VPC и позволяет маршрутизировать между ними трафик с использованием частных адресов IPv4 или IPv6.

### 5. Transit Gateway

AWS Transit Gateway выступает центральным транзитным узлом, связывающим несколько VPC, VPN-соединений и аккаунтов AWS.

### 6. VPC Endpoint типа Gateway

Конечная точка VPC типа Gateway позволяет организовать частное подключение VPC к поддерживаемым сервисам AWS и сервисам конечных точек на основе PrivateLink без интернет-шлюза и VPN.

### 7. VPC Endpoint типа Interface

Интерфейсная конечная точка VPC на базе AWS PrivateLink обеспечивает частное подключение VPC к поддерживаемым сервисам AWS, другим VPC и сервисам AWS Marketplace без IGW, VGW или устройства NAT.

### 8. Частное подключение к SaaS

AWS PrivateLink обеспечивает частную связь между VPC и сервисами, размещёнными в AWS или локальной инфраструктуре. Это удобно для безопасного доступа к SaaS-приложениям.
