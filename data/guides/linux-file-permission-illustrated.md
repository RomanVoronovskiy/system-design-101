## Принадлежность файла

Для каждого файла или каталога определены три категории пользователей:

* **Владелец (Owner):** пользователь, создавший файл или каталог.

* **Группа (Group):** группа может включать нескольких пользователей. Для всех её участников действуют одинаковые групповые права доступа к файлу или каталогу.

* **Остальные (Other):** пользователи, которые не являются владельцем и не входят в соответствующую группу.

## Права доступа

Для файла или каталога существуют три типа прав.

* **Чтение (r):** разрешает пользователю читать файл.

* **Запись (w):** разрешает изменять содержимое файла.

* **Выполнение (x):** разрешает запускать файл на выполнение.
