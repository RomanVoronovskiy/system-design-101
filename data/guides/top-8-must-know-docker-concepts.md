## Dockerfile

Содержит инструкции сборки образа Docker: задаёт базовый образ, зависимости и команду запуска.

## Образ Docker

Легковесный самостоятельный пакет со всем необходимым для запуска приложения: кодом, библиотеками и зависимостями. Образы собираются из Dockerfile и могут иметь версии.

## Контейнер Docker

Запущенный экземпляр образа Docker. Контейнеры изолированы друг от друга и от основной системы, обеспечивая защищённую и воспроизводимую среду выполнения приложений.

## Реестр образов Docker

Централизованное хранилище для размещения и распространения образов. Например, Docker Hub — публичный реестр по умолчанию; также можно создавать частные реестры.

## Тома Docker

Способ сохранять данные, создаваемые контейнерами. Тома находятся вне файловой системы контейнера и могут совместно использоваться несколькими контейнерами.

## Docker Compose

Инструмент описания и запуска приложений из нескольких контейнеров Docker. Упрощает управление всем стеком приложения.

## Сети Docker

Обеспечивают взаимодействие контейнеров между собой и с основной системой. Пользовательские сети позволяют изолировать контейнеры или разрешать только нужные соединения.

## Командная строка Docker — Docker CLI

Основной способ взаимодействия с Docker. Предоставляет команды сборки образов, запуска контейнеров, управления томами и других операций.
