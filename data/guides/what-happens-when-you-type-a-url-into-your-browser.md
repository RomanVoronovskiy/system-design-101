Схема выше показывает последовательность действий.

- Боб вводит URL в браузере и нажимает Enter. В этом примере URL состоит из четырёх частей:
  - **Схема** — *http://*. Она указывает браузеру установить соединение с сервером по протоколу HTTP.
  - **Домен** — *example.com*. Это доменное имя сайта.
  - **Путь** — *product/electric*. Это путь на сервере к запрашиваемому ресурсу — phone.
  - **Ресурс** — *phone*. Это имя ресурса, который хочет открыть Боб.

- Браузер определяет IP-адрес домена с помощью системы доменных имён (DNS). Для ускорения поиска данные кешируются на нескольких уровнях: в браузере, операционной системе, локальной сети и у интернет-провайдера.
  - Если адрес не найден ни в одном кеше, браузер обращается к DNS-серверам. Выполняется рекурсивный поиск до получения IP-адреса. Этот процесс будет рассмотрен в отдельном материале.

- Получив IP-адрес, браузер устанавливает с сервером TCP-соединение.

- Браузер отправляет HTTP-запрос. Он выглядит так:

  ```
  𝘎𝘌𝘛 /𝘱𝘩𝘰𝘯𝘦 𝘏𝘛𝘛𝘗/1.1
  𝘏𝘰𝘴𝘵: 𝘦𝘹𝘢𝘮𝘱𝘭𝘦.𝘤𝘰𝘮
  ```

- Сервер обрабатывает запрос и отправляет ответ. При успешной обработке код состояния равен 200. Ответ с HTML может выглядеть следующим образом:

  ```
  𝘏𝘛𝘛𝘗/1.1 200 𝘖𝘒
  𝘋𝘢𝘵𝘦: 𝘚𝘶𝘯, 30 𝘑𝘢𝘯 2022 00:01:01 𝘎𝘔𝘛
  𝘚𝘦𝘳𝘷𝘦𝘳: 𝘈𝘱𝘢𝘤𝘩𝘦
  𝘊𝘰𝘯𝘵𝘦𝘯𝘵-𝘛𝘺𝘱𝘦: 𝘵𝘦𝘹𝘵/𝘩𝘵𝘮𝘭; 𝘤𝘩𝘢𝘳𝘴𝘦𝘵=𝘶𝘵𝘧-8
  
  <**!𝘋𝘖𝘊𝘛𝘠𝘗𝘌** 𝘩𝘵𝘮𝘭>
  <**𝘩𝘵𝘮𝘭** 𝘭𝘢𝘯𝘨="𝘦𝘯">
  𝘏𝘦𝘭𝘭𝘰 𝘸𝘰𝘳𝘭𝘥
  </**𝘩𝘵𝘮𝘭**\>
  ```

- Браузер отображает полученный HTML.
