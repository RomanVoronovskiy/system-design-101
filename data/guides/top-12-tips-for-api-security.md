![](https://assets.bytebytego.com/diagrams/0027-12-tips-for-api-security.png)

* Используйте HTTPS
* Используйте OAuth2
* Используйте WebAuthn
* Применяйте API-ключи с разными уровнями доступа
* Реализуйте авторизацию
* Ограничивайте частоту запросов
* Версионируйте API
* Используйте списки разрешённых источников доступа
* Учитывайте риски безопасности API из списка OWASP
* Используйте API-шлюз
* Обрабатывайте ошибки
* Проверяйте входные данные
