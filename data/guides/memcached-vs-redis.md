Популярный вопрос на собеседованиях: чем отличаются Redis и Memcached?

Основные различия показаны на схеме. Благодаря поддерживаемым структурам данных Redis хорошо подходит для следующих задач:

* Подсчёт кликов и комментариев для каждой публикации — хеш (hash).
* Сортировка списка комментаторов и устранение повторов пользователей — упорядоченное множество (zset).
* Кеширование истории действий пользователей и фильтрация вредоносного поведения — zset и hash.
* Компактное хранение логических значений для огромного числа объектов, например статуса входа или наличия подписки, — битовая карта (bitmap).
