На диаграмме ниже показана архитектура Docker и то, как она работает, когда мы запускаем «сборку докера», «вытягивание докера» и «запуск докера».

В архитектуре Docker есть 3 компонента:

* **Докер-клиент**

Клиент Docker взаимодействует с демоном Docker.

* **Хост Docker**

Демон Docker прослушивает запросы Docker API и управляет объектами Docker, такими как изображения, контейнеры, сети и тома.

* **Реестр Docker**

В реестре Docker хранятся образы Docker. Docker Hub — это публичный реестр, которым может пользоваться каждый.

В качестве примера возьмем команду «docker run».

* Docker извлекает образ из реестра.
* Docker создает новый контейнер.
* Docker выделяет контейнеру файловую систему для чтения и записи.
* Docker создает сетевой интерфейс для подключения контейнера к сети по умолчанию.
* Docker запускает контейнер.
