Схема даёт общий обзор Web 1.0, Web 2.0 и Web 3.0.

![](https://assets.bytebytego.com/diagrams/0416-what-is-web-3.png)

* **Web 1.0 — только чтение**

С 1991 по 2004 год интернет напоминал **каталог статических страниц**. Пользователь просматривал содержимое, переходя по гиперссылкам, но почти не мог взаимодействовать с ним.

* **Web 2.0 — чтение и запись**

С 2004 года интернет развивается вокруг поисковых систем, социальных сетей и приложений с рекомендательными алгоритмами.

Приложения оцифровывают поведение людей и сохраняют данные об их взаимодействиях. Крупные компании используют эти сведения для рекламы — **одной из основных бизнес-моделей** Web 2.0.

Поэтому и говорят, что приложения знают вас лучше друзей, семьи и даже вас самих.

* **Web 3.0 — чтение, запись и владение**

Эта идея активно обсуждается с развитием блокчейна и децентрализованных приложений. Созданный пользователями контент хранится в IPFS (InterPlanetary File System), а **владение остаётся у самих пользователей**.

Чтобы получить доступ к данным, приложению нужно **разрешение** пользователя и **оплата** за их использование.

Изменение модели владения в Web 3.0 может привести к значительным инновациям.
