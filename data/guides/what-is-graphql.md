### Заменяет ли GraphQL REST API?

GraphQL — язык запросов к API и среда выполнения этих запросов на основе заданной системы типов данных. Он был разработан внутри Meta в 2012 году и опубликован в 2015-м.

В отличие от традиционного REST API, GraphQL позволяет клиенту запросить именно нужные данные, в том числе из нескольких источников за одно обращение. Это может повысить производительность веб- и мобильных приложений.

Сервер GraphQL располагается между клиентом и серверными сервисами. Он может объединить несколько обращений к REST API в один клиентский запрос и организует ресурсы в виде графа.

GraphQL поддерживает запросы, мутации — изменение данных ресурсов — и подписки для получения уведомлений об изменениях данных.

**Преимущества GraphQL**

* Более эффективная выборка данных.
* Клиент получает точнее определённый набор результатов.
* Строгая система типов управляет структурой сущностей и помогает уменьшить количество ошибок.
* Подходит для взаимодействия со сложными микросервисными системами.

**Недостатки GraphQL**

* Увеличение сложности.
* Риск избыточной выборки данных.
* Усложнение кеширования.
