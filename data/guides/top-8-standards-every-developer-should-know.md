## TCP/IP

Развиваемый организацией IETF стек протоколов TCP/IP — основа интернета и один из самых известных сетевых стандартов.

## HTTP

IETF также разрабатывает протокол HTTP, знание которого необходимо каждому веб-разработчику.

## SQL

Structured Query Language (SQL) — предметно-ориентированный язык управления данными.

## OAuth

OAuth (Open Authorization) — открытый стандарт делегирования доступа. Обычно он используется, чтобы предоставить сайту или приложению ограниченный доступ к данным пользователя, не раскрывая его пароль.

## HTML/CSS

Стандартизация HTML и его тегов помогает единообразно отображать страницы в разных браузерах и уменьшает усилия разработчиков на обеспечение совместимости.

Стандарты CSS часто используются совместно с HTML.

## ECMAScript

ECMAScript — стандартизированная спецификация скриптового языка, лежащая в основе нескольких языков программирования. Самый известный из них — JavaScript.

## Дата и время по ISO

Разработчики регулярно сталкиваются с несовместимыми форматами даты и времени. Стандарт ISO 8601 разработан Международной организацией по стандартизации — ISO — и задаёт общий формат обмена такими данными между странами, культурами и отраслями.

## OpenAPI

OpenAPI, также называемый OpenAPI Specification (OAS), — стандартизированный формат описания и документирования REST API.
