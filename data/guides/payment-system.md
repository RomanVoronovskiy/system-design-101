Вот как движутся деньги после нажатия кнопки «Купить» на Amazon или другом интернет-магазине.

## Обработка платежа

* Когда пользователь нажимает «Купить», создаётся платёжное событие, которое отправляется в платёжный сервис.
* Платёжный сервис сохраняет событие в базе данных.
* Одно событие может включать несколько платёжных поручений. Например, в одной корзине могут быть товары разных продавцов. Для каждого поручения платёжный сервис вызывает исполнителя платежа — payment executor.
* Исполнитель сохраняет поручение в базе данных.
* Затем он вызывает внешнего поставщика платёжных услуг — PSP, чтобы провести оплату банковской картой.
* После успешного исполнения платёжный сервис обновляет кошелёк, учитывая сумму, принадлежащую конкретному продавцу.
* Сервис кошелька сохраняет обновлённый баланс в базе данных.
* После успешного обновления баланса платёжный сервис вызывает сервис бухгалтерского реестра — ledger.
* Ledger добавляет новые записи в базу данных.
* Каждую ночь PSP или банки отправляют клиентам расчётные файлы. Они содержат остаток на банковском счёте и все транзакции по нему за день.
