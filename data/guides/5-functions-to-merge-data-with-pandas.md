Как нам быстро объединить данные без Microsoft Excel?

Вот 5 полезных функций pandas для анализа производственных данных.

- **Concat:** эта функция поддерживает вертикальную и горизонтальную комбинацию двух таблиц. Concat может быстро объединять данные из разных шардов.
- **Добавить:** эта функция поддерживает добавление данных в существующую таблицу. Append можно использовать в веб-сканерах. Новые данные можно добавить в таблицу при ее сканировании.
- **Объединить:** эта функция поддерживает горизонтальную комбинацию клавиш. Это работает аналогично объединению баз данных. Слияние можно использовать для объединения данных из разных доменов с одинаковыми ключами.
- **Join:** эта функция работает аналогично внешнему объединению базы данных.
- **Объединить:** эта функция позволяет применять вычисления при объединении двух таблиц. В приведенном ниже примере для ячейки выбирается меньшее значение. Комбайн полезен для процесса очистки данных.
