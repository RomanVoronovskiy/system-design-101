Во фронтенд-разработке важно не только показать содержимое, но и красиво его оформить. CSS — язык стилей, описывающий, как должны отображаться элементы веб-страницы.

* **Назначение CSS**

  CSS отделяет содержимое документа от его оформления. На ранних этапах развития веба HTML отвечал и за структуру, и за стиль.

  Теперь структура задаётся HTML, а оформление — CSS. Например, чтобы поменять цветовую схему страницы, достаточно изменить CSS-файл.

* **Как работает CSS**

  Правило CSS содержит селектор и набор свойств. Селектор определяет HTML-элементы, к которым применяется правило, а свойства задают цвет, размер, расположение и другие параметры оформления.

  Например, чтобы сделать текст всех абзацев синим, можно написать:

  p { color: blue; }

  Здесь p — селектор, а color: blue — объявление, задающее синий цвет текста абзаца.

* **Каскадирование**

  Каскад — ключевое понятие CSS. Когда правила стилей конфликтуют, браузер выбирает применяемое правило по системе приоритетов. Приоритет зависит, в частности, от типа селектора и порядка правил в исходном тексте.

* **Возможности построения макетов**

  Раньше CSS использовался главным образом для цвета текста, шрифтов и фона. Сегодня он позволяет создавать сложные макеты.

  Модули Flexbox и Grid упрощают адаптивную вёрстку и точное расположение элементов. Разработчикам больше не приходится полагаться на сложные таблицы и плавающие блоки.

* **Анимация**

  Анимация и интерактивные элементы могут заметно улучшить пользовательский опыт. В CSS3 появились средства для преобразования и анимации элементов без JavaScript. Например, правило @keyframes определяет последовательность анимации, а свойство `transition` задаёт плавные переходы между состояниями.

* **Адаптивный дизайн**

  CSS позволяет приспосабливать макет и оформление сайта к разным размерам и разрешениям экрана, обеспечивая удобный просмотр на телефонах, планшетах и компьютерах.
