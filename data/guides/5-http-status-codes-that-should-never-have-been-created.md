* **451 Недоступно по юридическим причинам:** Доступ запрещен по юридическим причинам.
* **218 This is Fine:** Создан по мотивам мема, обходит переопределения ошибок сервера.
* **420 Enhance Your Calm:** старый код Twitter для превышения ограничений скорости. Сейчас поменял на 429.
* **530 Site Frozen:** используется Pantheon для заблокированных сайтов, часто неоплаченных счетов.
* **418 Я чайник:** Классическая первоапрельская шутка, указывающая на ограничения сервера.
