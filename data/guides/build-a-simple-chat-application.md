Как нам создать простое приложение для чата с помощью Redis?

На диаграмме ниже показано, как мы можем использовать функциональность Redis pub-sub для разработки приложения чата.

## Этап 1: Инициализация соединения

* Шаги 1 и 2: Боб открывает приложение чата. Между клиентом и сервером устанавливается веб-сокет.

* Шаги 3 и 4: Сервер pub-sub устанавливает несколько подключений к Redis. Одно соединение используется для обновления моделей данных Redis и публикации сообщений в теме. Другие соединения используются для подписки и прослушивания обновлений тем.

* Шаги 5 и 6. Клиентскому приложению Боба требуется список участников чата и список исторических сообщений. Информация извлекается из Redis и отправляется клиентскому приложению.

* Шаги 7 и 8: Поскольку Боб является новым участником, присоединяющимся к приложению чата, сообщение публикуется в теме «member\_add», и в результате другие участники приложения чата могут видеть Боба.

## Этап 2: Обработка сообщений

* Шаг 1: Боб отправляет сообщение Алисе в приложении чата.

* Шаг 2. Новое сообщение чата добавляется в Redis SortedSet с помощью вызова zadd. Сообщения чата сортируются по времени прибытия. Затем сервер pub-sub публикует сообщение чата в теме «сообщения», чтобы подписчики могли его получить.

* Шаг 3: Клиентское приложение Алисы получает сообщение чата от Боба.
