Uber — одна из наиболее технологически новаторских компаний. Рассмотрим инструменты, которые она использует для CI/CD.

![](https://assets.bytebytego.com/diagrams/0398-uber-tech-stack-ci-cd.png)

Примечание: материал основан на публикациях инженерного блога Uber. Если заметите неточности, сообщите авторам.

* **Планирование проектов:** JIRA.
* **Бэкенд-сервисы:** Spring Boot. Для ускорения выпуска изменений конфигурации компания создала собственную систему Flipr.
* **Качество кода:** NullAway помогает выявлять проблемы с нулевыми ссылками, NEAL выполняет статические проверки, а Piranha удаляет устаревшие флаги функциональности.
* **Репозиторий:** Uber придерживается подхода монорепозитория и активно использует Bazel.
* **Тестирование:** SLATE управляет краткоживущими тестовыми окружениями, Shadower воспроизводит рабочий трафик для нагрузочного тестирования. Ballast разработан для обеспечения плавной работы пользовательского интерфейса.
* **Платформа экспериментов:** основана на глубоком обучении. Некоторые её части, включая Pyro, опубликованы с открытым исходным кодом.
* **Сборка:** сервисы упаковываются в контейнеры с помощью uBuild — инструмента на основе Buildkite.
* **Развёртывание приложений:** Netflix Spinnaker обеспечивает удобный и эффективный выпуск приложений в рабочую среду.
* **Мониторинг:** Uber разработала собственные системы и использует платформу uMetric на базе Cassandra, чтобы поддерживать единообразный подход.
* **Специализированные инструменты:** Peloton используется для планирования мощностей, распределения задач и эксплуатации. Crane создаёт многооблачную инфраструктуру для оптимизации затрат. uAct и панель OnCall помогают отслеживать события и организовывать дежурства.
