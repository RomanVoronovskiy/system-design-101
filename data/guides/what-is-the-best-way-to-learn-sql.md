SQL (Structured Query Language — язык структурированных запросов) был стандартизован в 1986 году. За последующие 40 лет он стал основным языком реляционных СУБД. Чтение большого стандарта, например упомянутого в оригинале ANSI SQL 2016, занимает много времени. Как лучше подойти к изучению?

## Составляющие SQL

Выделяют пять групп команд:

* **DDL** — определение данных: CREATE, ALTER, DROP.
* **DQL** — запросы к данным: SELECT.
* **DML** — изменение данных: INSERT, UPDATE, DELETE.
* **DCL** — управление доступом: GRANT, REVOKE.
* **TCL** — управление транзакциями: COMMIT, ROLLBACK.

Бэкенд-разработчику может понадобиться большая часть этих возможностей. Аналитику особенно важно хорошо понимать DQL. Выбирайте темы, наиболее полезные для ваших задач.
