Kubernetes — платформа оркестрации контейнеров с открытым исходным кодом. Она автоматизирует развёртывание, масштабирование и управление контейнеризированными приложениями.

Изначально Kubernetes разработала Google, а теперь проект поддерживает CNCF — Cloud Native Computing Foundation.

В этой шпаргалке собраны важнейшие команды Kubernetes для разных задач:

* Настройка Kubernetes
* Общее управление кластером
* Работа с развёртываниями Kubernetes
* Просмотр состояния подов Kubernetes
* Поиск неисправностей и настройка
* Другие команды для работы с сервисами, ConfigMap и управления Ingress.
