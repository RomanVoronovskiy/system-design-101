API-шлюз располагается между клиентами и сервисами и обеспечивает их взаимодействие через API.

* **API-шлюз помогает создать экосистему.**
  Через шлюз пользователи получают доступ к более широкому набору инструментов. Участники экосистемы сотрудничают, чтобы улучшать интеграции для пользователей.
* **API-шлюз помогает создать маркетплейс API.**
  Маркетплейс предоставляет всем участникам базовые возможности. Разработчики и компании могут создавать в такой экосистеме новые решения и продавать API на общей площадке.
* **API-шлюз обеспечивает совместимость разных платформ.**
  При работе с несколькими платформами шлюз помогает организовать взаимодействие между различными сложными архитектурами.
