Сеть доставки контента (CDN) — это географически распределенные серверы (также называемые пограничными серверами), которые обеспечивают быструю доставку статического и динамического контента. Давайте посмотрим, как это работает.

Предположим, Боб, живущий в Нью-Йорке, хочет посетить веб-сайт электронной коммерции, развернутый в Лондоне. Если запрос пойдет на серверы, расположенные в Лондоне, ответ будет довольно медленным. Поэтому мы развертываем серверы CDN рядом с местом проживания Боба, и контент будет загружаться с ближайшего сервера CDN.

## Как работает CDN

* Боб вводит в браузере [www.myshop.com](http://www.myshop.com/). Браузер ищет имя домена в локальном кэше DNS.

* Если доменное имя не существует в локальном кэше DNS, браузер обращается к сопоставителю DNS для разрешения имени. DNS-преобразователь обычно находится у поставщика услуг Интернета (ISP).

* DNS-преобразователь рекурсивно разрешает доменное имя (подробности см. в моем предыдущем посте). Наконец, он просит авторитетный сервер имен разрешить доменное имя.

* Если мы не используем CDN, авторитетный сервер имен возвращает IP-адрес для [www.myshop.com](http://www.myshop.com/). Но в случае с CDN авторитетный сервер имен имеет псевдоним, указывающий на [www.myshop.cdn.com](http://www.myshop.cdn.com/) (доменное имя сервера CDN).

* Распознаватель DNS запрашивает авторитетный сервер имен разрешить [www.myshop.cdn.com](http://www.myshop.cdn.com/).

* Авторитетный сервер имен возвращает имя домена для балансировщика нагрузки CDN [www.myshop.lb.com](http://www.myshop.lb.com/).

* Распознаватель DNS запрашивает балансировщик нагрузки CDN разрешить [www.myshop.lb.com](http://www.myshop.lb.com/). Балансировщик нагрузки выбирает оптимальный пограничный сервер CDN на основе IP-адреса пользователя, интернет-провайдера пользователя, запрошенного контента и нагрузки на сервер.

* Балансировщик нагрузки CDN возвращает IP-адрес пограничного сервера CDN для [www.myshop.lb.com](http://www.myshop.lb.com/).

* Теперь мы наконец-то получили реальный IP-адрес для посещения. DNS-преобразователь возвращает IP-адрес браузеру.

* Браузер посещает пограничный сервер CDN для загрузки контента. На серверах CDN кэшируется два типа содержимого: статическое содержимое и динамическое содержимое. Первый содержит статические страницы, изображения, видео; последний включает результаты периферийных вычислений.

* Если кеш пограничного сервера CDN не содержит контента, он передается на региональный сервер CDN. Если контент по-прежнему не найден, он отправится на центральный сервер CDN или даже отправится к источнику — лондонскому веб-серверу. Это называется распределительной сетью CDN, где серверы развернуты географически.
