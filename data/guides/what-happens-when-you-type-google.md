![What Happens When You Type google.com Into a Browser?](https://assets.bytebytego.com/diagrams/0410-what-happens-when-you-type-google-in-your-browser.png)

1. Вы вводите адрес сайта в адресную строку браузера.
2. Браузер проверяет собственный кеш. Если нужной записи нет, необходимо определить IP-адрес.
3. Начинается поиск через DNS — своего рода поиск номера в телефонном справочнике. Запрос проходит через корневые DNS-серверы, серверы домена верхнего уровня и авторитетные серверы. В итоге получается IP-адрес.
4. Браузер устанавливает TCP-соединение. Например, при HTTP/1.1 клиент и сервер выполняют трёхстороннее рукопожатие TCP: SYN, SYN-ACK и ACK.
5. После успешного установления соединения браузер отправляет HTTP-запрос, а сервер возвращает файлы HTML, CSS и JavaScript.
6. Браузер обрабатывает полученные данные: разбирает HTML и строит деревья DOM и CSSOM.
7. Затем выполняется JavaScript и формируется изображение страницы. Обработка включает выделение токенов, синтаксический разбор, построение дерева отрисовки, расчёт расположения элементов и рисование.
8. Веб-страница появляется на экране.
