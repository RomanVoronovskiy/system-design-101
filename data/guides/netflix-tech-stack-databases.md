Инженеры Netflix выбирают разные базы данных, чтобы обеспечить потоковую передачу в большом масштабе.

* **Реляционные базы данных:** MySQL используется для платёжных операций, подписок, налогов и выручки. CockroachDB поддерживает многорегиональную архитектуру active-active, глобальные транзакции и процессы конвейеров данных.
* **Колоночные базы данных:** в основном используются для аналитики. Redshift и Druid хранят структурированные данные, Spark обрабатывает данные в конвейерах, а Tableau служит для визуализации.
* **Базы данных «ключ — значение»:** основное решение — EVCache, построенный на Memcached. Netflix использует его более десяти лет в большинстве сервисов для кеширования разных данных, в том числе главной страницы и персональных рекомендаций.
* **Базы данных с широкими столбцами:** обычно выбор по умолчанию — Cassandra. В ней хранят самые разные данные: сведения о видео и актёрах, пользователей, устройствах и истории просмотров.
* **Базы данных временных рядов:** для хранения и агрегации метрик Netflix разработал открытую базу данных Atlas, работающую в памяти.
* **Неструктурированные данные:** основное хранилище — S3. В нём размещаются изображения, видео, файлы метрик и логи. Для хранения больших данных вместе с S3 также используется Apache Iceberg.
